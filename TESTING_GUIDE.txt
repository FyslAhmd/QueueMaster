================================================================================
                        TROUBLESHOOTING
================================================================================

If you encounter issues:

1. CHECK TERMINAL
   - Look for error messages in the terminal running `npm run dev`
   - MongoDB connection errors will appear here

2. CHECK BROWSER CONSOLE
   - Open DevTools (F12 or Ctrl+Shift+I)
   - Look at Console tab for JavaScript errors
   - Look at Network tab for failed API calls

3. CHECK .ENV.LOCAL
   - Ensure MONGODB_URI is correct
   - Ensure NEXTAUTH_SECRET is set
   - Ensure NEXTAUTH_URL matches your localhost

4. RESTART SERVER
   - Stop server (Ctrl+C in terminal)
   - Run `npm run dev` again

5. CLEAR BROWSER DATA
   - Clear cookies for localhost
   - Clear localStorage
   - Try incognito/private window
