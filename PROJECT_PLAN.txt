================================================================================
         SMART APPOINTMENT & QUEUE MANAGER - PROJECT PLAN
================================================================================

Project: Smart Appointment & Queue Manager
Created: January 24, 2026
Tech Stack: Next.js 15, TypeScript, Tailwind CSS 4, Prisma, PostgreSQL

================================================================================
                           PROJECT OVERVIEW
================================================================================

A full-stack web application to manage service appointments, staff availability,
and customer queues with real-time conflict detection and auto-assignment.

Core Features:
- User authentication with demo login
- Staff & service management
- Appointment scheduling with conflict detection
- Waiting queue with position tracking
- Real-time dashboard analytics
- Activity logging

================================================================================
                         FEATURE SPECIFICATIONS
================================================================================

1. AUTHENTICATION
--------------------------------------------------------------------------------
   - Email + Password registration
   - Login with validation
   - Demo user button: "Login as Demo User"
   - Demo credentials seeded: demo@example.com / demo123
   - Session management via NextAuth.js v5
   - Protected route middleware
   - Redirect to /dashboard after successful login

2. STAFF MANAGEMENT
--------------------------------------------------------------------------------
   - Create staff member (Name, Service Type, Daily Capacity)
   - Edit staff details
   - Delete staff member
   - Toggle availability status (Available / On Leave)
   - View staff list with current day's appointment count
   - Display format: "Farhan (3/5 appointments today)"
   - Filter by service type
   - Search by name

3. SERVICE MANAGEMENT
--------------------------------------------------------------------------------
   - Create service (Name, Duration, Required Staff Type)
   - Duration options: 15, 30, 60 minutes
   - Edit service details
   - Activate/Deactivate services
   - Delete service
   - List services with status badges

4. APPOINTMENT MANAGEMENT
--------------------------------------------------------------------------------
   CREATE APPOINTMENT:
   - Select service (dropdown)
   - Enter customer name
   - Select date & time
   - Select staff (with capacity display)
   - Staff dropdown shows: "Farhan (3/5 appointments today)"
   
   CAPACITY WARNING:
   - If staff at max capacity: 
     "⚠️ Farhan already has 5 appointments today"
   - Block selection if exceeded
   
   NO STAFF AVAILABLE:
   - Appointment goes to Waiting Queue
   - Show message: "No staff available. Added to waiting queue."
   
   CONFLICT DETECTION:
   - Check for time overlap with same staff
   - Show error: "This staff member already has an appointment at this time."
   - Offer options: Pick another staff / Change time
   
   VIEW APPOINTMENTS:
   - List view with filters (date, staff, status)
   - Calendar view (weekly/daily)
   - Status badges: Scheduled (blue), Completed (green), 
                    Cancelled (gray), No-Show (red)
   
   EDIT APPOINTMENT:
   - Update customer name, time, staff, service
   - Re-validate conflicts on edit
   
   CANCEL APPOINTMENT:
   - Soft delete (mark as CANCELLED)
   - Log activity

5. WAITING QUEUE MANAGEMENT
--------------------------------------------------------------------------------
   QUEUE DISPLAY:
   - Ordered by appointment time (earliest first)
   - Show position: 1st, 2nd, 3rd...
   - Show customer name, service, requested time
   - Real-time updates via SSE
   
   ASSIGN FROM QUEUE:
   - Button: "Assign From Queue"
   - Auto-select earliest eligible appointment
   - Check staff availability and capacity
   - Assign to available staff
   - Remove from queue
   - Log activity: "Appointment for 'John' assigned to Riya"
   
   MANUAL ASSIGNMENT:
   - Select specific queue entry
   - Choose available staff
   - Assign and log

6. CONFLICT DETECTION ALGORITHM
--------------------------------------------------------------------------------
   VALIDATION STEPS:
   1. Check time overlap with existing appointments for selected staff
   2. Query: startTime < newEnd AND endTime > newStart
   3. If overlap found → reject with message
   4. Use database transaction with serializable isolation
   5. Unique slotKey constraint as final safety net
   
   RACE CONDITION PREVENTION:
   - Database-level unique constraint on slotKey
   - Transaction isolation level: Serializable
   - Optimistic locking pattern

7. DASHBOARD
--------------------------------------------------------------------------------
   STATS CARDS:
   - Total Appointments Today (count)
   - Completed (count + percentage)
   - Pending (count)
   - Waiting Queue Count
   
   STAFF LOAD SUMMARY:
   - Visual progress bars for each staff
   - Color coding: Green (OK) / Yellow (Warning) / Red (Full)
   - Example display:
     Riya — 4/5 [████████░░] OK
     Farhan — 5/5 [██████████] FULL
   
   QUICK ACTIONS:
   - Create Appointment button
   - View Queue button
   - Assign From Queue button
   
   TODAY'S SCHEDULE:
   - Timeline view of upcoming appointments
   - Show customer name, service, staff, time

8. ACTIVITY LOG
--------------------------------------------------------------------------------
   TRACKED ACTIONS:
   - Queue → Staff assignments
   - Appointment status changes
   - Staff availability changes
   - Appointment cancellations
   
   DISPLAY:
   - Show latest 5-10 logs
   - Timestamp format: "11:45 AM"
   - Human-readable messages:
     "11:45 AM — Appointment for 'John Doe' auto-assigned to Riya"
     "12:10 PM — Appointment moved from queue to Farhan"
   
   LOAD MORE:
   - Infinite scroll or "Load More" button
   - Paginated API

QUEUE (Server Actions):

================================================================================
                         VALIDATION RULES (ZOD SCHEMAS)
================================================================================

STAFF VALIDATION:
- name: string, min 2 chars, max 100 chars
- serviceType: string, min 2 chars
- dailyCapacity: number, min 1, max 50

SERVICE VALIDATION:
- name: string, min 2 chars, max 100 chars
- duration: enum [15, 30, 60]
- requiredStaffType: string

APPOINTMENT VALIDATION:
- customerName: string, min 2 chars, max 100 chars
- serviceId: valid service ID
- staffId: valid staff ID (optional, null for queue)
- startTime: future datetime
- Server-side conflict detection (time overlap)
- Server-side capacity validation

USER VALIDATION:
- email: valid email format
- password: min 6 chars, max 100 chars
- name: string, min 2 chars
